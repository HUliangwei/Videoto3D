# Videoto3D v1.2.0 · Tutorial Publishing

## README inline video

当前 README 使用 GitHub `user-attachments` 原生视频：

```text
https://github.com/user-attachments/assets/b8d11389-6d23-45dc-a846-226d778f2979
```

该 URL 单独占一行，因此 GitHub README 会直接显示视频播放器。

## Local source

```text
recordings/Videoto3D_Workflow_Tutorial_v1.2.0.mp4
```

`recordings/` 继续保持在 `.gitignore`，不要把原始 MP4 作为普通 Git Blob 提交。

## Repository publishing flow

```text
GitHub README
└─ Inline Workflow Tutorial
   └─ github.com/user-attachments/assets/...

Local project
└─ recordings/
   └─ original tutorial MP4
```

如未来更换视频，只需：
1. 在 GitHub README 编辑页上传新 MP4；
2. 取得新的 `user-attachments` URL；
3. 替换 README 中这一行 URL。
